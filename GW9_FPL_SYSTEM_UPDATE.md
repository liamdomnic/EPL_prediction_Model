Each player card shows:
- ⚽ **Goals**: Number of goals × 6 points
- 🎯 **Assists**: Number of assists × 4 points
- 🧤 **Clean Sheet**: ✓ or ✗ (6 points for DEF/GK only)
- 📊 **Base**: 2 points for playing the match

**Total** = Goals + Assists + Clean Sheet + Base
